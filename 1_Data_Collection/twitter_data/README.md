# Twitter Data Collection

This project uses the [TwitterScrapper](https://github.com/DaBabyOx/TwitterScrapper) to collect Twitter data for sentiment analysis.

## Steps to Collect Data

1. **Clone the Repository**  
    Clone the TwitterScrapper repository:
    ```bash
    git clone https://github.com/DaBabyOx/TwitterScrapper.git
    ```

2. **Install Dependencies**  
    Navigate to the cloned directory and install the required dependencies:
    ```bash
    cd TwitterScrapper
    pip install -r requirements.txt
    ```

3. **Configure Scraper**  
    Update the configuration file or script to specify the keywords, hashtags, or accounts you want to scrape.

4. **Run the Scraper**  
    Execute the scraper to collect data:
    ```bash
    python scraper.py
    ```

5. **Save Data**  
    Ensure the collected data is saved in a format suitable for analysis, such as CSV or JSON.

## Notes
- Refer to the [TwitterScrapper documentation](https://github.com/DaBabyOx/TwitterScrapper) for detailed usage instructions.
- Ensure compliance with Twitter's API and data usage policies.
